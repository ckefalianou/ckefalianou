### Hi, I'm Christine 👋

Full-stack developer. Half-stack sanity.

At work I mostly write **Laravel and Vue**. In my spare time I build small tools for my own day-to-day annoyances. Sometimes they turn out useful for other people too. I work on Linux, which is how I ended up writing hardware support for my own peripherals.

#### 🐧 Open source contributions

- **[openrazer](https://github.com/openrazer/openrazer)** is the Linux driver and daemon for Razer devices. I added kernel-driver support for:
  - Razer Strider Chroma Extended ([#2461](https://github.com/openrazer/openrazer/pull/2461))
  - Razer Mouse Dock Pro, tested with a Basilisk V3 Pro 35K ([#2471](https://github.com/openrazer/openrazer/pull/2471))
- **[polychromatic](https://github.com/polychromatic/polychromatic)** is an RGB lighting GUI for Linux. I added the device map for the Mouse Dock Pro ([#548](https://github.com/polychromatic/polychromatic/pull/548)).
